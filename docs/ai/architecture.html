Kiến Trúc Tách Biệt Tuyệt Đẹp Của Airbyte

Khám phá bản chất thiết kế mở rộng tối cao: Phân tách rõ ràng giữa Bộ não điều khiển trung tâm (Platform) và Cổng xử lý dữ liệu độc lập (Connector).

🧠

Airbyte Platform Bộ Não / Control Plane

Đóng vai trò là hệ điều hành và trung tâm chỉ huy trung tâm. Quản lý toàn bộ cấu hình, lịch trình chạy, phân quyền, giao diện người dùng, và theo dõi log.

  • Quản lý Vận hành: Cung cấp Web UI tuyệt đẹp trên cổng 8010, định tuyến an sau qua Traefik HTTPS.
  • Lịch trình (Scheduling): Lên kế hoạch tự động kích hoạt các luồng đồng bộ (Sync Jobs).
  • Quản lý Trạng thái: Lưu trữ trạng thái gia tăng (Incremental State) để đồng bộ thông minh không trùng lặp.
  • Orchestrator: Triển khai, giám sát và tắt các container Connector trên VPS một cách tự động khi hoàn thành nhiệm vụ.
🔌

Airbyte Connector Công Cụ / Execution Plane

Là các khối logic độc lập, đóng gói hoàn chỉnh dưới dạng các container Docker. Nơi chúng ta trực tiếp tùy biến, nâng cấp cổng Clickhouse hoặc viết connector mới.

  • Tách biệt Tuyệt đối (Decoupled): Không can thiệp vào mã nguồn Platform. Lập trình độc lập trong thư mục airbyte-integrations/connectors/.
  • Cơ chế "Gọi-Khi-Cần" (On-Demand): Không chạy thường trực 24/7 trên VPS để tiết kiệm tối đa RAM. Chỉ khởi chạy khi được Platform ra lệnh và tắt ngay sau khi xong việc.
  • Giao tiếp Dòng lệnh (CLI-based): Trao đổi thông tin chuẩn hóa qua luồng Standard I/O (STDOUT, STDERR) với các lệnh spec, check, read, write.

Bản Đồ Vận Hành Tương Tác 1Connector

Nhấp vào bất kỳ nút (node) nào trong sơ đồ dưới đây để xem vai trò chi tiết trong luồng hoạt động

💻 Local IDE / Code Workspace (Phát triển Connector)

Nơi nhà phát triển trực tiếp làm việc trên mã nguồn của connector (airbyte-integrations/connectors/destination-clickhouse). Bạn tùy biến các tính năng ghi dữ liệu, sữa đổi logic nạp bulk hay điều chỉnh tệp cấu hình Java/Kotlin. Toàn bộ mã nguồn Platform trung tâm được bảo lưu hoàn toàn nguyên vẹn.

🚀 GitHub Actions CI/CD Pipeline (Đóng gói Tự động)

Khi bạn đẩy code mới lên nhánh staging, GitHub Actions sẽ tự động kích hoạt. Nó biên dịch dự án bằng JDK 21 và chạy tác vụ Docker chuyên dụng của dự án: ./gradlew :airbyte-integrations:connectors:destination-clickhouse:dockerBuildx để đóng gói code thành một Docker Image staging siêu nhẹ.

📦 Docker Hub Image Registry (Kho Lưu Trữ Độc Lập)

Ảnh Docker đóng gói hoàn tất sẽ được tự động gắn thẻ và đẩy trực tiếp lên kho chứa Docker Hub cá nhân của bạn: membeedev/destination-clickhouse:staging. Nơi này đóng vai trò phân phối độc lập, cho phép bất kỳ hệ thống Airbyte Platform nào ở bất cứ đâu kéo về cài đặt chỉ bằng một cú nhấp chuột.

☁️ VPS Staging Server (Vận Hành & Điều Phối)

Trái tim vận hành thực tế. Công cụ abctl quản trị hạ tầng Platform chạy an toàn trên cổng 8010. Khi bạn yêu cầu chạy một luồng đồng bộ, Airbyte Platform trên VPS sẽ tự động ra lệnh kéo ảnh membeedev/destination-clickhouse:staging từ Docker Hub về, tạo một container ngắn hạn để ghi dữ liệu trực tiếp vào database ClickHouse của bạn rồi dọn dẹp sạch sẽ sau khi hoàn tất.

So Sánh Chi Tiết Vai Trò Cấu Phần

Tiêu chí so sánh Airbyte Platform (Khung điều khiển) Airbyte Connector (Công cụ xử lý)
Vai trò chính Điều phối, quản trị cấu hình, lên lịch biểu, giám sát log, hiển thị UI. Trực tiếp đọc dữ liệu từ nguồn (Source) hoặc ghi dữ liệu xuống đích (Destination).
Công nghệ sử dụng React (Frontend Webapp), Temporal Workflow, Java (Micronaut APIs), MinIO. Kotlin / Java (sử dụng Bulk CDK của Gena-AI) hoặc Python (Airbyte CDK).
Chu kỳ sống trên VPS Chạy thường trực 24/7 như các Daemon Services để lắng nghe yêu cầu và Web UI. Chỉ chạy khi có lệnh đồng bộ (On-Demand), tự động tắt và xóa container ngay khi xong.
Cách thức triển khai Cài đặt bằng công cụ chuẩn abctl kéo từ các Docker images gốc ổn định. Đóng gói tùy biến riêng biệt thành ảnh Docker, đẩy lên Docker Hub thông qua CI/CD GitHub.
Nơi thực hiện code/nâng cấp Rất ít khi đụng vào mã nguồn platform trừ khi nâng cấp tính năng lõi của tổng hệ thống. Nơi chúng ta trực tiếp nâng cấp hàng ngày trong các thư mục connectors của repo.

Sổ Tay Vận Hành & Lập Trình Phát Triển

Sử dụng các câu lệnh sau tại máy tính Local để phát triển, đóng gói và đồng bộ hóa Connector Clickhouse: 

# 1. Di chuyển vào thư mục connector Clickhouse
cd airbyte-integrations/connectors/destination-clickhouse

# 2. Biên dịch và Đóng gói Docker Image bằng Gradle với task chính xác
./gradlew :airbyte-integrations:connectors:destination-clickhouse:dockerBuildx

# 3. Gắn nhãn tag staging và đẩy lên tài khoản Docker Hub của bạn
docker tag airbyte/destination-clickhouse:dev membeedev/destination-clickhouse:staging
docker push membeedev/destination-clickhouse:staging

Các câu lệnh hữu ích để quản lý, lấy thông tin đăng nhập hoặc nâng cấp cụm Airbyte Platform trên máy chủ VPS: 

# 1. Truy vấn mật khẩu đăng nhập của Airbyte Web UI trên VPS
abctl local credentials

# 2. Xem trạng thái các dịch vụ pod Airbyte đang vận hành trên cụm VPS
abctl local status

# 3. Nâng cấp cụm Airbyte Platform lên phiên bản mới nhất
abctl local install --host 1connector.hub.vn --port 8010 --low-resource-mode

Chạy các lệnh kiểm thử đặc tả (spec) và kiểm thử khả năng kết nối cơ sở dữ liệu Clickhouse thực tế ngay trên VPS: 

# 1. Trích xuất đặc tả đầu vào của Connector trên VPS (Kiểm tra lỗi DI khởi động)
docker run --rm membeedev/destination-clickhouse:staging spec

# 2. Chạy kiểm tra kết nối (Check Connection) nạp tệp cấu hình JSON thật
docker run --rm \
  -v /home/vmxclaw/airbyte-staging/test-config.json:/airbyte/test-config.json \
  membeedev/destination-clickhouse:staging check --config /airbyte/test-config.json
